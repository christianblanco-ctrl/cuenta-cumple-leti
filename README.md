# Cuenta del cumple de Leti

## Publicarlo (una sola vez)

1. **Crea el repo:** en GitHub, *New repository*, nómbralo `cuenta-cumple-leti`, déjalo **público** y sube estos archivos tal cual (`index.html`, `ticket.json` y la carpeta `reclamos/`).
2. **Activa Pages:** *Settings → Pages → Build and deployment*: Source **Deploy from a branch**, rama **main**, carpeta **/ (root)**. En 1–2 minutos queda en `https://TU-USUARIO.github.io/cuenta-cumple-leti/`.
3. **Genera el token:** *Settings (de tu perfil) → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token*.
   - **Expiration:** 3–7 días.
   - **Repository access:** *Only select repositories* → `cuenta-cumple-leti`.
   - **Permissions → Repository permissions → Contents:** *Read and write*.
   - Copia el token (empieza con `github_pat_…`).
4. **Arma la liga y compártela por WhatsApp:**
   `https://TU-USUARIO.github.io/cuenta-cumple-leti/#k=github_pat_XXXX`

El token nunca se sube al repo: viaja después del `#`, que el navegador no envía al servidor. Cuando todos hayan pagado, borra el token en GitHub.

## Cómo se calcula

- Cada quien marca cuántas piezas consumió de cada platillo.
- Si entre todos marcan más piezas de las que hay (p. ej., una jarra compartida), el platillo se reparte en proporción a lo que marcó cada quien.
- Lo que nadie reclame se suma a lo de Leti.
- Lo de Leti (su consumo + lo no reclamado) se divide entre los otros 4.
- Se agrega 10 % de propina sobre lo que paga cada quien.
